# TecRob - Sistema de Gestión

Sistema integral para tienda de reparación y venta de computadoras.

## Stack Tecnológico

- **Backend:** Java + Spring Boot
- **Frontend:** Angular + Material + Tailwind
- **Base de Datos:** MySQL

## Estructura del Proyecto

- `backend/` → API REST en Spring Boot (Java)
- `frontend/` → Aplicación Angular
